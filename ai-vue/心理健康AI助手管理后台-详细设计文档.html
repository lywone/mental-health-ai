1 背景与目标

心理健康AI助手面向终端用户提供 AI 咨询与情绪记录能力，平台侧缺少统一的运营管理入口。本期新增管理后台， 为管理员提供固定入口，完成四类工作：查看平台数据、管理知识文章、查阅咨询会话记录、查阅用户情绪日志。

预期可观察结果：管理员登录进入后台后，可在统一布局下通过左侧菜单到达四个页面，完成对应查看与管理操作，并可退出登录回到登录页。 登录流程为前端假登录（预置账号 admin / 123456，见 4.5），真实后端鉴权体系不在本期范围。

3 全局设计

3.1 技术与组件约定

  • 组件库：Element Plus（需求明确指定）。
  • 布局容器：el-container 体系（el-header / el-aside / el-main）。
  • 路由：vue-router，history 模式，后台路由统一前缀 /back/。
  • 图表：Element Plus 不含图表组件，需引入图表库绘制折线图 / 柱状图 假设采用 ECharts，待确认。
  • 数据来源：本地 Mock 数据（Q1 已确认）——按第 4 章字段表在项目内构造静态数据模块，含图表所需时间序列；后续可平滑替换为真实接口。
  • 鉴权：前端假登录（Q2 已确认）——预置账号 admin / 123456，登录态存 localStorage，路由守卫统一校验（见 4.5 FR-L02）。
  • 语言与构建：沿用 ai-vue 现状（JavaScript + Vite），组件与 Element Plus API 已配置按需自动导入。

3.2 整体布局骨架

FR-G01 页面采用 el-container 三段式骨架：导航头固定顶部、左侧菜单固定、 右侧内容区独立滚动（滚动条出现在内容区右缘，而非浏览器窗口）。窗口尺寸变化时，头部与侧栏保持固定，仅内容区伸缩。

其余加载、空态、错误反馈为跨页面共享规则，统一见第 6 章，各页面不再重复定义。

4.5 登录页 /login Q2 已确认 · 本期新增

目的：管理员进入后台的唯一入口。本期为前端假登录（预置账号校验），用于跑通「登录 → 守卫 → 后台 → 退出」完整闭环；接入真实后端后仅需替换校验逻辑与登录态来源。

布局：不套用后台三段式布局，全屏浅灰底、居中白色卡片：品牌 Logo 与名称、账号输入框、密码输入框、登录按钮，见图 8。

图 8 · 登录页线框（假登录演示）

功能点

编号功能触发与行为
FR-L01登录提交登录表单时：先做非空校验（失败则字段级红字提示，不提交）；通过与预置账号（admin / 123456，存于 Mock 常量）比对。成功：localStorage 写入登录态（键名如 back_auth），消息提示「登录成功」，跳转到 redirect 参数指定页面（无参数时默认 /back/dashboard）；失败：统一提示「账号或密码错误」。
FR-L02访问控制（路由守卫）全局前置守卫校验 localStorage 登录态：未登录访问 /back/* → 重定向 /login 并携带 redirect 参数；已登录访问 /login → 重定向 /back/dashboard。

以下规则为全文档唯一权威定义，各页面引用执行，不重复定义。

R3时间格式列表与详情统一 YYYY-MM-DD HH:mm；纯日期场景（图表 X 轴）使用 MM-DD 或 YYYY-MM-DD。
R4分页表格统一使用 el-pagination：默认每页 10 条，可选 10 / 20 / 50，显示总条数；筛选条件变更后回到第 1 页 默认值待确认。
R5文章状态流转草稿 → 已发布（行内「发布」）；已发布 → 已下架（行内「下架」）；已下架 → 已发布（行内「发布」）；任意状态可删除（FR-A04）。状态间不可逆跳过（如草稿不可直接下架）。
R6评分分档情绪评分 0–10：0–3 低（红）、4–6 中（橙）、7–10 高（绿）；用于列表徽标着色，仅视觉分层，不改变数值。
R7敏感数据边界咨询记录与情绪日志仅管理后台内查看；本期不提供导出、分享、批量操作；管理员账号之外不可访问后台路由。
